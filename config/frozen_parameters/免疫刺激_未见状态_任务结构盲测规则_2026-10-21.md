# 免疫刺激未见状态：任务结构优先 v0.1 独立盲测规则

冻结日期：2026-10-21

## 数据

Xu 等 2026 拟南芥根模式触发免疫单细胞数据。作者提供 5 种刺激的完整 `根区 × 细胞类型` 差异响应表：flg22、Pep1、Chitin、SCOOP10、SCREW1。差异分析使用 `FindMarkers(..., logfc.threshold = 0)`，因此可利用完整 `avg_logFC` 排序，而不是只看显著差异基因。

## 任务类型

`missing_state`：目标细胞状态在处理条件下视为完全未观测；同一刺激、同一响应阶段的其他状态可见。

严格沿用《任务结构优先证据选择规则_v0.1_冻结_2026-10-21.md》：只有来源响应具有足够强共享结构时，才允许输出细粒度基因候选。

## 来源共享结构门槛

沿用已经冻结的 v0.1 数值，不为本数据修改：

- 第一共同轴能量 >= 0.50
- 状态两两 Spearman 相关中位数 >= 0.35
- 第一共同轴有效贡献状态比例 >= 0.50

三项同时满足：`允许跨状态基因级迁移`。

任一不满足：`拒判基因级迁移`。此时仍冻结同一共享预测供揭晓后诊断，但它不属于主输出，不得事后因表现好而改称成功预测。

## 预测

对每种刺激，仅使用十个来源状态：

1. 技术基因范围 = 十个来源差异表中共同出现的基因；
2. 每个基因预测响应 = 十个来源状态 `avg_logFC` 的等权平均；
3. 按预测响应绝对值降序排列；
4. 方向取平均响应符号。

不使用四个目标状态的任何数值选择基因、调权、调门槛或选模型。

## 揭晓评分

每个刺激 × 每个目标状态分别计算：

- 完整响应 Spearman：主报冻结技术宇宙（目标表缺失基因按 0 响应处理），并附目标表实际出现基因上的相关；
- 前100 / 250 / 500 / 1000 候选重叠；
- 相对随机期望的富集倍数；
- 重叠候选方向一致率；
- 目标表对冻结技术宇宙的覆盖比例。

每种刺激再汇总四个目标状态的中位数。

## 单体 RDS 的盲法限制与防火墙

作者把来源和目标差异表保存在同一个 RDS 中，无法做到目标字节从未进入反序列化进程。因此本测试使用确定性双阶段防火墙：

1. 本规则、目标状态、来源状态、分割脚本、冻结脚本、目标提取脚本、评分脚本全部先写死；
2. 第一次下载作者 RDS 后，独立 R 进程只把十个允许来源状态写入 `source_only`，不输出目标状态；随后删除完整 RDS/压缩包；
3. 冻结程序只能读取 `source_only`，计算共享结构、路线和候选，并生成哈希清单；此时目标文件不存在；
4. 冻结完成后重新下载同一作者文件，由预先写死的目标提取脚本只导出四个目标状态；
5. 再运行预先写死的评分器。

因此这不是“目标字节从未被任何进程读取”的最强物理隔离盲测；但目标没有参与任何分析决策、共享结构计算、候选生成或规则修改。结果中必须如实标注这一点。
