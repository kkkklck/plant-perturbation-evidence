# 任务结构优先扰动证据框架 v0.2：方法规范

冻结日期：2026-10-21

## 1. 方法目标

本框架不尝试建立一个统一的“植物虚拟细胞”，也不要求精确重建所有基因的未来表达量。

它回答一个更窄、也更接近实验决策的问题：

> **在当前已经拥有的证据下，哪些基因最值得优先验证，方向大致是什么，以及现有证据是否足以支持这种粒度的结论？**

主要输出是候选优先级，而不是完整转录组模拟。

---

## 2. 第一原则：先识别“缺失的是什么”

证据选择首先由预测任务结构决定，而不是由“处理了几小时”“看起来像急性还是慢性”等人工时间标签决定。

### 2.1 同一状态的未来时间 `future_time`

目标：同一细胞状态、组织或实验系统在更晚时间点的响应尚未观测。

只要存在可靠的近期同状态历史：

- **默认主证据 = 最近一次可靠同状态响应**；
- 更早历史只用于判断连续性和稳定性；
- 跨状态共同响应可以作为辅助对照，但不能仅因“共享度高”覆盖已有最近同状态历史。

依据：盐胁迫、侧根、缺铁、GSE46205、低 pH、缺硫连续冻结结果。GSE46205 特别显示，即使来源第一共同轴达到72.2%，时间预测仍应优先同状态最近历史。

### 2.2 未见细胞状态 `missing_state`

目标：同一处理阶段下，目标细胞状态没有可用处理响应，但其他状态已经观测。

此时跨状态共同响应属于直接可用证据，但必须先通过来源共享结构门槛。

冻结门槛：

- 第一共同轴能量 >= 0.50；
- 来源状态两两 Spearman 相关中位数 >= 0.35；
- 第一共同轴有效贡献状态比例 >= 0.50。

三项同时满足：允许输出基因级跨状态候选。

任一不满足：拒判细粒度基因级迁移；可以保留“存在一定共享信息”的诊断，但不能与通过门槛的场景使用同等语气。

依据：热激目标状态留出；2026 根免疫五刺激独立盲测。后者以60%覆盖率换取更高可靠性：允许组12个目标状态完整相关中位数0.578、前100命中61；拒判组8个状态分别0.276和31。

### 2.3 跨实验迁移 `cross_experiment`

目标：整个目标实验尚未做或没有对应处理表达，只能借用独立实验中的响应程序。

要求：

- 来源至少有2个可比较状态或独立来源；
- 使用与 `missing_state` 相同的共享结构门槛；
- 只有通过门槛时才允许基因级跨实验迁移。

来源程序使用有符号等权平均，不根据目标实验调权。

依据：38℃45分钟根单细胞热激共同程序迁移到独立37℃1小时整株幼苗热激，前100命中64/100。

### 2.4 全新组合干预 `combination`

目标：双突变、多突变或组合干预本身从未观测，但组成单扰动已经有响应。

基础预测：

`组合响应 = 各组成单扰动有符号响应之和`

候选按组合响应绝对值排序。

同时必须报告：

- 最强单成员响应；
- 单成员主导比例；
- 组成响应方向一致度。

解释边界：

- 相加可以预测“哪些基因值得看”；
- 相加不保证优于最强单成员；
- 强主导成员存在时，应并列保留最强单成员解释。

依据：PAT 三个双突变和一个三突变完全留出测试。

### 2.5 恢复 / 状态切换 `recovery`

目标：系统已经发生状态切换，例如复水、解除处理或恢复。

规则：

- 不默认把原扰动轨迹简单取反；
- 若切换后的其他状态响应已经存在，则按 `missing_state` 的共享结构门槛决定能否迁移；
- 若没有切换后来源，默认拒绝细粒度基因级预测，而不是用“原轨迹反向”补答案。

依据：15分钟复水中跨状态共同程序远优于简单反向干旱轨迹。

## 3. 第二原则：响应结构只在任务结构允许时决定迁移

来源共享结构用于回答：

> **“这些来源是否像同一个可迁移程序？”**

它不回答：

> **“有没有共享程序就应该覆盖同状态时间历史？”**

计算来源状态响应矩阵 `E`（基因 × 来源状态）后：

1. 对完整基因矩阵进行奇异值分解；
2. 第一共同轴能量 = 第一奇异值平方 / 全部奇异值平方和；
3. 状态相关 = 来源响应两两 Spearman 相关中位数；
4. 有效贡献状态数 = 第一轴状态载荷平方分布的逆 Simpson 指数；
5. 有效贡献比例 = 有效状态数 / 来源状态数；
6. 留一状态共同相关仅作为诊断，不进入当前硬门槛。

冻结共享门槛保持：0.50 / 0.35 / 0.50。

---

## 4. 第三原则：候选排序优先于完整表达重建

默认报告：

- 前100；
- 前250；
- 前500；
- 前1000。

对揭晓测试报告：

- 前 k 候选重叠；
- 相对随机期望的富集倍数；
- 重叠候选方向一致率；
- 完整响应 Spearman 作为次级描述指标。

不以完整向量相关是否“足够高”作为候选排序有效性的唯一判据。

---

## 5. 第四原则：不确定性不是一个统一的0–100分数

框架只输出可解释的诊断状态：

- `已排序`：当前任务存在冻结规则支持的主证据；
- `允许细粒度迁移`：未见状态/跨实验来源通过共享结构门槛；
- `拒判`：来源不足或共享结构未通过门槛；
- `来源敏感`：候选对来源移除、组成成员选择等明显敏感；
- `组合主导`：一个组成成员贡献占比较高；
- `机制专门候选`：有独立、方向明确且上下文相容的机制证据。

“拒判”不等于零信息。它只表示现有证据不足以支持与高共享场景相同粒度和语气的基因级输出。

---

## 6. 机制证据：只允许局部专门加权

机制证据不是第六种全局预测模型，而是一个**叠加层**。

### 6.1 可以进入专门层的机制证据

至少满足：

1. **独立性**：机制证据不是从当前待预测目标中提取；
2. **特异性**：指向具体调控关系、移动因子、直接功能靶点或明确通路；
3. **方向性**：若要用于方向预测，必须有激活/抑制或正负方向依据；
4. **上下文相容**：组织、细胞位置、发育阶段或构建方式不能明显违背机制发生条件。

### 6.2 程序行为

机制证据不得通过任意倍数直接修改全局 `priority_score`。

程序只做三件事：

- 在默认排序中标记 `mechanism_supported`；
- 记录机制期望方向与默认预测方向是否一致；
- 额外输出 `mechanism_candidates.tsv`，作为局部专门候选面板。

若只有机制先验、没有可运行的默认任务证据，则只输出机制候选面板，不声称获得全转录组排序。

### 6.3 为什么不做全局机制加权

SHR 新目标冻结测试显示：

- 8个有独立功能方向支持的正向直接靶点中4个进入真实恢复前10%，5.0倍富集，P=0.005；
- 6/8方向符合预期，7/8救援后更接近WT；
- 但更宽泛的ChIP前25结合候选只有1.67倍富集，P=0.214。

因此：

> **“功能明确、带方向、上下文相容”的机制证据可以局部提权；“曾经结合过”本身不足以覆盖默认排序。**

## 7. 各任务的证据优先级

### 未来时间

1. 最近可靠同状态历史；
2. 更早同状态历史用于连续性诊断；
3. 跨状态共同响应仅辅助；
4. 窄机制证据可作为局部叠加层。

### 未见状态

1. 先做来源共享结构门槛；
2. 通过 → 等权共同响应；
3. 不通过 → 基因级拒判；
4. 窄机制证据可单独形成专门候选，但不得把整个被拒判场景改称“可预测”。

### 跨实验

1. 来源共享结构；
2. 通过 → 等权共同程序；
3. 不通过 → 拒判细粒度跨实验迁移；
4. 机制证据局部叠加。

### 新组合

1. 组成单扰动有符号相加；
2. 最强单成员并列保留；
3. 主导性和互补性诊断；
4. 机制证据只针对已支持基因局部叠加。

### 恢复 / 状态切换

1. 已有切换后其他状态 → 共享结构门槛；
2. 通过 → 共同响应；
3. 无切换后来源或共享不足 → 拒判；
4. 不使用简单反向旧轨迹作为默认补偿。

---

## 8. 输入与输出规范

统一入口面向已经整理好的“基因 × 证据”表，不直接绑定 Seurat、Monocle 或某个单细胞格式。

### 必需输入

- `gene`：基因标识；
- 任务所需的一个或多个响应列；
- 可选技术基因筛选列。

### 可选机制叠加表

至少包含：

- `gene`；
- `mechanism_tier`；
- `expected_direction`：`up` / `down` / `unknown`；
- `context_compatible`：true/false；
- `evidence_note`。

### 主输出

`ranking.tsv.gz`：

- priority_rank
- gene
- predicted_response
- predicted_direction
- priority_score
- evidence_role
- 来源支持与一致性诊断
- 机制叠加标记（若提供）

`mechanism_candidates.tsv`：

- 只包含机制支持基因；
- 保留原默认排名；
- 不创建任意“机制加权分”。

`manifest.json`：

- 方法版本；
- 任务类型；
- 输入与规则哈希；
- 是否拒判；
- 共享结构；
- 证据来源；
- 机制叠加状态。

## 9. 当前证据状态

### 已有较强前瞻 / 目标留出支持

- 同状态未来时间：盐胁迫、侧根、缺铁、GSE46205、缺硫；
- 未见细胞状态：热激；
- 未见状态的共享门槛与拒判：五刺激根免疫独立测试；
- 跨实验迁移：独立热激；
- 新遗传组合：PAT 双突变 / 三突变；
- 窄机制专门证据：SHR 中柱非移动救援。

### 边界 / 负结果

- RNA动力学能恢复发育方向，但不能直接承担长期遗传扰动全转录组预测；
- GSE46205证明“强共享”不能覆盖已有同状态近期历史；
- 低 pH 目标重复性很差，限制单基因方向结论；
- PAT 中强主导成员使简单相加不一定优于最强单成员；
- SHR 宽泛ChIP结合名单没有显著机制增益。

### 尚未作为主结论验证

- 真正跨细胞移动因子的受体组织完全留出预测；
- 复杂高阶组合的普适组合规则；
- 任意远缘物种上的全自动跨物种路由。

---

## 10. v0.2 的一句话定义

> **先判断任务里缺失的是什么，优先使用与该缺失结构直接对应的证据；只有在来源结构支持时才允许迁移，只有在机制证据足够具体、带方向并与上下文相容时才做局部专门加权，证据不足则降低粒度或拒判。**
