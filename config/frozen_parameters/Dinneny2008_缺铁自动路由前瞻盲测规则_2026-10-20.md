# Dinneny2008 缺铁自动路由前瞻盲测规则

冻结日期：2026-10-20

## 目的

这是 `来源结构路由规则_v0.1_冻结_2026-10-20.md` 冻结之后的第二份新数据测试。

第一份高盐数据被规则前瞻判定为“路线歧义”。本轮不修改任何阈值，直接在独立扰动——缺铁——上检验来源结构是否会自然落入强共享型、强状态特异型或继续落在歧义区。

## 数据

### 细胞层来源：GSE10501 + 标准细胞层对照

GSE10501 提供五个根细胞层在缺铁24小时后的表达：
1. epidermis + lateral root cap
2. columella root cap
3. cortex
4. endodermis + quiescent center
5. stele

年龄均为6日龄，平台为 ATH1。

GSE10501 没有重复发布标准条件细胞层；标准条件使用同一研究体系中 GSE7641 的对应五个6日龄标准细胞层：
- 同一 GFP 标记体系；
- 同一 ATH1 平台；
- 每个标准细胞层3个重复。

GSE10501 缺铁样本：
- epidermis + lateral root cap：4个重复；
- 其余四个细胞层：各3个重复。

每个细胞层响应：

`response_state_24h = mean(log2 -Fe24h) - mean(log2 standard)`

该五状态响应矩阵用于来源结构判定，并构建共享24小时预测。

### 整根时间历史：GSE10502

冻结阶段只允许使用：
- 标准条件：GSM265461 / GSM265462；
- 3小时：GSM265463 / GSM265464；
- 6小时：GSM265465 / GSM265466；
- 12小时：GSM265467 / GSM265468；
- 24小时：GSM265469 / GSM265470。

48小时目标：
- GSM265471 / GSM265472。

72小时：
- GSM265473 / GSM265474。

**冻结完成之前，48小时和72小时样本不得下载或读取。**

## 表达处理

所有样本均为同一 ATH1 Affymetrix 平台的 MAS5 / MAS5.0 处理后信号。

- 信号必须为有限正值；
- 转换为 `log2(signal)`；
- 排除 `AFFX-` 控制探针；
- 候选单位先固定为 ATH1 `ID_REF` 探针；
- 只保留细胞层来源、标准细胞层和整根前目标样本中共同存在且数值完整的探针。

探针到基因的注释不参与冻结路由或候选排序。

## 自动路由

严格使用已冻结的 `来源结构路由规则_v0.1`，不修改阈值。

### 强共享型
同时满足：
- 第一共同轴占比 >= 0.50；
- 五状态两两 Spearman 相关中位数 >= 0.35；
- 第一轴有效贡献状态比例 >= 0.50。

主预测：
`shared_24h = 五细胞层 response_state_24h 等权有符号平均`

### 强状态特异型
同时满足：
- 第一共同轴占比 <= 0.40；
- 五状态两两相关中位数 <= 0.15；
- 第一轴有效贡献状态比例 <= 0.30；
- 存在最近同状态历史。

本数据存在整根24小时历史，因此若满足结构条件：

主预测：
`persistent_24h = whole_root_24h - baseline`

### 路线歧义
若两类均不满足：
- 冻结为“路线歧义”；
- 同时保留 shared_24h 和 persistent_24h；
- 不指定赢家；
- 不平均二者。

## 冻结对照

无论自动路由结果如何，都冻结：
1. `shared_24h`：五细胞层共同响应；
2. `persistent_24h`：整根24小时最近历史；
3. `whole_12h`；
4. `whole_6h`；
5. `whole_3h`。

## 评价

在冻结探针范围内：
- 完整响应 Spearman 相关；
- 全探针非零方向一致率；
- top100 / 250 / 500 / 1000 重叠；
- 随机富集倍数；
- 重叠候选方向一致率。

如果自动路由给出唯一主路线，主检验是：
> 冻结主路线是否优于预先冻结的另一条主要路线。

如果仍为路线歧义：
> 不定义事前赢家，仅记录真实路线结构并继续校准。

不设事后 PASS/FAIL 数值门槛。
