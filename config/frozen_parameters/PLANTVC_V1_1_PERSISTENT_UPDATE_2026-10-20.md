# PlantVC v1.1 — 持续型扰动规则更新

更新时间：2026-10-20，在 GSE153103 6h 首次前瞻结果揭晓后、读取 12h 表达值之前。

## 6h 新证据
只用 0/1/3h 预测 6h：
- v1 持续性加分模型：technical full-vector rho ~0.589，top100 30/100；
- 简单 3h baseline：rho ~0.599，top100 同为 30/100，top250/500/1000 略优；
- 1h baseline 明显更弱。

因此：
- “持续型扰动应该优先依赖最近同状态历史”得到支持；
- “额外给早期持续性加分能提高排序”没有得到支持。

## v1.1 简化规则
对于明确的持续型 / 进展型扰动：

1. 默认有符号预测 = 最近一个可用时间点相对基线的响应；
2. 候选排名 = 最近响应的绝对值；
3. 更早时间点不参与主排名，只用于描述：
   - 方向是否持续；
   - 生物重复是否稳定；
   - 置信度是否应该降低；
4. 不做线性外推；
5. 不因为历史不一致就删除基因，只降低置信度。
