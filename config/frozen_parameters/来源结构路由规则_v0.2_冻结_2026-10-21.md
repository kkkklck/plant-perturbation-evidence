# 来源结构路由规则 v0.2（冻结）

冻结日期：2026-10-21

本文件定义从此刻开始用于新目标的来源结构路由。其修改依据包括此前热激、复水、侧根、九激素回顾校准，以及 v0.1 在 Dinneny 高盐与缺铁48小时两个前瞻目标上的表现。已揭晓目标不得再用于宣称本规则前瞻成功。

## 1. 目的

在目标响应完全不可见时，只根据已有来源响应结构决定：

- 跨状态共同响应是否足以作为主要证据；
- 是否应优先使用最近同状态历史；
- 或证据结构是否处于中间区域，应明确输出路线歧义。

不依据目标结果修改阈值，不输出未经校准的正确概率。

## 2. 来源结构量

对同一扰动条件下多个状态的响应矩阵计算：

- 第一共同轴响应能量占比；
- 状态两两 Spearman 相关中位数；
- 第一共同轴有效贡献状态比例。

有效贡献状态比例只用于排除“单一状态撑起高共同轴”的伪共享，不再作为强状态特异型的必要条件。

## 3. 冻结规则

### 强共享型

同时满足：

- 第一共同轴响应能量占比 >= 0.50；
- 状态两两相关中位数 >= 0.35；
- 第一共同轴有效贡献状态比例 >= 0.50。

输出：跨状态共同响应作为主证据。

### 强状态特异型

同时满足：

- 第一共同轴响应能量占比 <= 0.40；
- 状态两两相关中位数 <= 0.20；
- 存在可用的最近同状态历史。

输出：最近同状态历史作为主证据。

### 路线歧义

不满足上述任一强区域时：

- 不强行选择唯一赢家；
- 同时保留可用证据路线；
- 明确标记路线歧义。

## 4. 为什么从 v0.1 修改

v0.1 要求强状态特异型还必须“第一共同轴有效贡献状态比例 <= 0.30”。Dinneny 缺铁24小时来源结构显示：第一共同轴只有37.16%、状态两两相关中位数只有0.187，但该弱共同轴仍分散在约3/5个状态。48小时揭晓后，跨状态共同响应完整相关为-0.056，而整根24小时最近历史为0.526。

这说明“弱共同轴由多个状态贡献”并不能单独证明共享迁移有效。共享路线首先要求共同轴本身足够强；有效贡献状态比例应作为强共享判定中的防伪条件，而不是反向阻止状态特异判定。

该修改来自48小时揭晓后的校准，因此不能回头把48小时结果算作 v0.2 的前瞻验证。

## 5. 第一个未揭晓顺序目标

Dinneny 缺铁72小时在本规则冻结时尚未下载、未读取。

根据已经冻结的24小时来源几何：

- 第一共同轴 = 0.3716；
- 状态两两相关中位数 = 0.1865；
- 且存在整根同状态时间历史；

v0.2 将该任务自动判定为：**强状态特异型**。

在72小时目标揭晓前，主预测必须使用最新可用的同状态历史，即整根48小时相对0小时的响应；24小时、12小时等更早历史只作为对照，不得替代主预测。
