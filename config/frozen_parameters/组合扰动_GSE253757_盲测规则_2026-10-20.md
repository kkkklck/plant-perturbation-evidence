# GSE253757 组合扰动完全留出盲测规则

日期：2026-10-20

## 目的

检验一个此前未看过的遗传组合，能否仅由其组成单突变的转录响应提前排出真正的强响应基因。

本测试不再使用“PlantVC”名称。当前只把方法称为“植物扰动证据优先级框架”。

## 数据

GSE253757，拟南芥地上部 RNA 测序。三个 PAT 家族成员均在 summ2-8 背景中构建。

样本映射仅由 GEO 元数据确定：

- 1–3：summ2-8，共同背景
- 4–6：pat1-1 summ2-8
- 7–9：path1-4 summ2-8
- 10–12：path2-1 summ2-8
- 13–15：pat1-1 path1-4 summ2-8
- 16–18：pat1-1 path2-1 summ2-8
- 19–21：path1-4 path2-1 summ2-8
- 22–24：pat1-1 path1-4 path2-1 summ2-8

冻结前只允许读取样本 1–12 的表达值。样本 13–24 的表达值全部封存。

## 冻结目标

一次性冻结四个完全未见组合：

1. pat1 + path1
2. pat1 + path2
3. path1 + path2
4. pat1 + path1 + path2

## 预处理

每个样本独立计算 CPM，并转换为 log2(CPM + 1)。

单突变响应定义为：

`该单突变三个重复的平均 log2(CPM+1) - summ2-8 三个重复的平均 log2(CPM+1)`

技术基因范围只由样本 1–12 决定：

`CPM >= 1 的预目标样本数 >= 3`

目标组合样本不能参与技术基因范围定义。

## 冻结组合规则

设三个单突变响应分别为：

- A = pat1
- B = path1
- C = path2

则：

- pat1 + path1：预测 = A + B
- pat1 + path2：预测 = A + C
- path1 + path2：预测 = B + C
- 三突变：预测 = A + B + C

候选排序统一按预测响应绝对值从大到小。

相加与取平均在候选排序和方向上等价，因此不把平均作为额外模型。

组成响应之间的方向一致程度只作为置信描述，不参与排名：

`一致度 = |组成响应之和| / 组成响应绝对值之和`

## 冻结对照

每个组合同时保留：

- 各组成单突变自身的候选排序；
- 每个基因上取绝对变化最大的组成单突变作为保守对照。

这些对照均只使用样本 1–12。

## 揭晓后的主评价

每个目标组合独立计算其三个重复相对 summ2-8 的平均响应，并在冻结技术基因范围内报告：

- 完整响应向量 Spearman 相关；
- top100 / 250 / 500 / 1000 强响应候选重叠；
- 相对随机期望的富集倍数；
- 超几何检验；
- 重叠候选方向一致率；
- 真实 top-k 候选在冻结预测中的排名百分位；
- 三个目标重复之间的响应可重复性。

主问题不是要求完整转录组精确重建，而是：

1. 组合规则能否显著压缩真实强响应候选空间；
2. 组合规则是否优于只使用任一组成单突变；
3. 从双扰动扩展到三扰动后，组合性是否仍保留。

## 冻结纪律

- 不因目标结果修改组合公式；
- 不因目标结果修改技术基因阈值；
- 不因目标结果选择更有利的单突变或基因子集；
- 不把揭晓后的协同残差重新加入冻结预测；
- 无论结果强弱均保留四个目标的完整结果。
